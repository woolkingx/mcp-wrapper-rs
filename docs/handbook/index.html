Project Summary

mcp-wrapper-rs wraps stdio MCP servers with a lightweight Rust supervisor proxy. It answers stable MCP discovery requests from cache, exposes wrapper management through the unified mcp.wrapper tool, and forwards backend-owned dynamic calls to a child MCP server only when needed. Normal mode gives each wrapper its own lazy backend; daemon mode lets multiple wrapper sessions share one broker and one backend.

client stdio -> mcp_interface -> runtime_manager -> mcp_manager | tools | backend_manager -> child MCP server daemon client stdio -> daemon_manager -> broker_manager -> mcp_manager | tools | backend_manager

Reader Contract

Use README.md for install and usage. Use this handbook for architecture truth, owner boundaries, data/state/control flow, and gates. Use CLAUDE.md for local agent execution rules. Use tests and scripts only as proof surfaces, not as architecture sources.

GATE-PAGE-01Cache build/refresh drains backend list pagination and rejects unissued frontend cursors with JSON-RPC -32602.integration tests, timeouts.rs

GATE-PROXY-01Pass-through calls remap IDs, reuse a live backend, and clean process groups on exit.integration tests, orphan check
