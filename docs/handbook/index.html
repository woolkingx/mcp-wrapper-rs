Project Summary

mcp-wrapper-rs wraps stdio MCP servers with a lightweight Rust proxy. It answers stable MCP discovery requests from cache and forwards dynamic calls to a child MCP server only when needed. Normal mode gives each wrapper its own lazy backend; daemon mode lets multiple wrapper sessions share one broker and one backend.

client stdio -> mcp_interface -> runtime_manager -> mcp_manager | backend_manager -> child MCP server daemon client stdio -> daemon_manager -> broker_manager -> mcp_manager | backend_manager

Reader Contract

Use README.md for install and usage. Use this handbook for architecture truth, owner boundaries, data/state/control flow, and gates. Local agent act rules and execution plans are not part of the public release surface. Use tests and scripts only as proof surfaces, not as architecture sources.
