Daemon Fixture Isolation

A daemon broker identity is derived from its backend target. Tests that do not intentionally prove sharing must use unique backend arguments, because fixture cleanup is allowed to stop only the broker that fixture owns. Tests that prove two-client sharing explicitly reuse one unique target inside that test and no other test.

Current Caution

The handbook records proof routes, not current pass status. Always run the relevant command in the current worktree before claiming a gate is green.
