Data

Primary Product Data

The primary data is small: JSON-RPC messages carrying MCP methods and MCP discovery/call content. Backend lifecycle, daemon sockets, cache epochs, and logs are supporting state, control, or evidence data. They exist to keep the primary MCP data flowing correctly; they are not the product data itself.

Primary dataOwnerMeaning
JSON-RPC request, response, and notification envelopesmcp_interfaceThe legal transport shape across client, wrapper, and child server stdio.
MCP tool/resource/prompt discovery resultsmcp_managerThe stable capability surface cached and replayed by the wrapper.
MCP dynamic calls and backend repliesruntime_manager or broker_manager composition over backend_managerThe request-scoped data that must pass through without semantic ownership by the wrapper.

Named Unknowns

The wrapper does not know backend semantics beyond MCP capabilities, response envelopes, health signals, and explicit hook readback. It also cannot assume a daemon-shared backend is safe for stateful servers; README keeps that as a user-facing boundary.
