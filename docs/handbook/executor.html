Executor

Execution Roles

ExecutorMay doMust not do
mcp_interfaceRead/write/build JSON-RPC, classify MCP and wrapper methods.Own cache, backend process, or daemon state.
mcp_managerInitialize backend, parse capabilities, refresh discovery cache, track cache epoch.Spawn or kill child processes.
backend_managerSpawn child, map responses, observe process state, execute restart/stop/ping hooks, kill process group.Invent MCP method semantics or mutate cache directly.
runtime_managerRun normal stdio loop, route requests, forward active peer responses.Own backend lifecycle truth.
daemon_managerConnect/start broker and relay bytes.Own shared backend state.
broker_managerMultiplex sessions, own active peer-session routing, coordinate shared backend/cache managers.Broadcast request/response messages without ownership.
