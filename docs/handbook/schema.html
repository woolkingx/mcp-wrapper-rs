Legal Shapes

The executable contract is JSON-RPC 2.0 over line-delimited stdio plus MCP method envelopes. The repository does not currently have a root schema.json; proof uses tests/fixtures/mcp-schema.json and the conformance validator.

Rule

New protocol shape support starts with route ownership and conformance proof. Hook responses must be local wrapper JSON-RPC results with stable fields for backend generation, cache epoch, state, and readback evidence. Wrapper tool shapes start in src/tools; CLI argv parsing and MCP tools/call parsing are projections of that schema, not independent schema owners.
