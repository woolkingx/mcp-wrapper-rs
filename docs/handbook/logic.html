Invariants

Route decisions stay pure. Backend request IDs are internal and must be restored before the client sees the response. Process groups are killed explicitly before runtime exit. mcp.wrapper actions must not pass through to backend tools and must not mutate lifecycle or cache state except by calling the existing owner APIs. Future multi-backend routing must use a registry-owned route table; string guessing at call time is illegal. Hook/observe control must not treat arbitrary notifications as lifecycle truth. Peer responses must be forwarded without holding the backend slot mutex that protects lifecycle state. Spawn failures must become observable degraded state instead of repeated blind respawn attempts.
