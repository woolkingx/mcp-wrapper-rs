Layer Responsibilities

LayerOwnsMust not
docs/handbook/*.htmlArchitecture, topology, flow, gates, canonical status.Become a changelog or quickstart clone.
README.mdPublic promise, install, usage, links.Own long-form architecture truth.
CLAUDE.mdAgent act rules, local invariants, release checklist.Grow into the full handbook.
docs/plan/*.mdTemporary action plan and verification list.Create new architecture semantics.
tests/Proof and regressions.Replace architecture explanation.

Maintenance Rules

  • Keep active Markdown reachable from index.html.
  • Use 200 lines as the split checkpoint and 500 as the hard maximum per handbook file.
  • Flowgraph files are projections of handbook truth, not replacement truth.
  • When README and handbook disagree, fix the stale surface instead of letting both compete.
